# Лабораторная работа №1 — векторизация обхода графа

## Задание 1

Освоение векторизации.
Цель: научиться выполнять оптимизацию (векторизация) программ.
Постановка задачи
Оптимизировать заданную программу автоматически или полуавтоматически с помощью
компилятора, а также при желании с помощью intrinsics. Сравнить время работы следующих
вариантов программы:
- исходная программа, без оптимизации
- исходная программа, оптимизированная только с помощью ключей компилятора,
- программа, векторизованная полуавтоматически (с помощью директив и ключей компилятора и
незначительной правки кода),
...

Отчёт (полужирным шрифтом выделена обязательная часть, которая должна быть в отчете)
- постановка задачи,
- описание используемой вычислительной системы и компилятора,
- листинг программы на С/C++ или ссылка на репозиторий,
- результаты выполнения задания: описание выполненных оптимизаций и полученное время
работы. Для ручной векторизации или полуавтоматической привести время расчёта, полученных
на разных этапах оптимизации.
- таблица результатов последовательных оптимизаций (векторизации), сравнение с
теоретическими результатами,
- листинг на ассемблере фрагмента кода,
- вывод по результатам выполнения задания.
Варианты заданий выбираются из задач студентом согласно порядкового номера в списке по
соответствующему модулю. Может быть предложена и согласована своя собственная задача.
Задачи:
1. Умножение плотных матриц больших размерностей.
2. Транспонирование плотных матриц больших размерностей.
3. Сложение и вычитание плотных матриц больших размерностей.
4. Приведение плотных матриц больших размерностей к ступенчатому виду.
5. Нахождение обратной матрицы (плотная матрица большой размерности).
6. Численное интегрирование с помощью сплайнов.
5. Вычисление числа pi через интегральный синус.
8. Обход графа.
Во всех случаях использовать ключи оптимизации, дающие наименьшее время работы программы,
и наиболее позднее (эффективное) из доступного векторного расширения. По возможности
обеспечить использование команд выровненного чтения и записи векторов. В программе с ручной
векторизацией минимизировать количество обращений к памяти. На каждом этапе ручной
оптимизации проверить, что время работы программы уменьшилось.

## Реализация

Вариант **8 — обход графа (BFS)**. Граф в формате CSR, две измеряемые версии: `bfs_scalar` и `bfs_neon_scan` (загрузка четырёх соседей через NEON, обновление расстояний — как в скалярной версии). Корректность — сравнение с `bfs_reference` (`std::queue`).

**NEON** — SIMD-набор для ARM (128-битные векторы, до четырёх `uint32` за операцию)

## Запуск

```bash
make                    
./scripts/run.sh        
./scripts/inspect.sh    
```

Аргументы: `n m seed repeats` (по умолчанию `100000 500000 12345 9`).

```bash
./bfs_O0 100000 500000 12345 9
./bfs_O3 100000 500000 12345 9
```
